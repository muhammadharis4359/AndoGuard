SLIDE 1 — PROJECT MISSION & IDENTITY

AndoGuard: Production-Grade Android Binary Analysis & Auditing Framework

A library-first, offline-first security assessment platform designed for authorized reverse engineering, compliance verification against OWASP MASVS, and runtime instrumentation.

🎯 Problem Statement

Modern Android reverse engineering toolchains suffer from brittle cloud dependencies, lack of thread safety in analysis data structures, and fragmented static/dynamic tooling.

💡 Solution Architecture

Clean hexagonal architecture with an abstract backend adapter layer, single-worker thread queue (BackendExecutor), and deterministic SQLite WAL session persistence.

📐 Standard Alignment

Automated static auditing rigorously mapped to the official OWASP Mobile Application Security Verification Standard (MASVS v2.0).

SLIDE 2 — TECHNICAL METHODOLOGY & ADAPTER LAYER

Engine Architecture: Dual-Backend & Thread Concurrency

Thread-Safe Execution

Androguard parsing structures are notoriously thread-affine. AndoGuard routes all analysis queries through a dedicated BackendExecutor task queue, preventing race conditions.

Multi-Engine Adapter

Dynamic detection layer supporting Androguard 4.x and 5.x with automatic fallback to pure-Python parsers for AXML, ARSC, DEX, and X.509 certificates.
